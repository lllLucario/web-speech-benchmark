    How scoring works

    • WER / MER. English references use word error rate. References with Han characters use mixed error rate, counting each Han character and each English word as one unit. Error rate = (substitutions + deletions + insertions) ÷ reference units. Accuracy = 1 − error rate.
    • Normalized is the default. Both modes ignore case and punctuation. Normalized also maps English number words zero–twenty to digits and skips the configured fillers for WER and MER. For example, two coffees and 2 coffees score the same.
    • Critical phrases. Each phrase must appear as a contiguous sequence of units. Normalized applies the same number rules here and keeps fillers. The match rate is the number of phrases found divided by the number checked.
    • Recognition success. A run needs a non-blank original final transcript, a normal end and no recorded errors. A failed run can still receive a score. With an empty transcript and a scorable reference, the error rate is 100%.
    • Latency. Results show time between browser events separately from accuracy. Missing events show N/A and are excluded from latency averages and percentiles.

    Saved scores use the browser’s original final transcript. Your edits are saved separately.
